# Java prácticas

Ejercicios de Java, cada uno en su propio package dentro de `src/`.

| Package | Qué hace |
|---|---|
| `ej1_printYScanner` | Pide el nombre por teclado con `Scanner` y lo muestra por pantalla. |
| `ej2_ifsYComparaciones` | Pide nombre y edad y, con `if / else if / else`, dice si eres VIP, mayor o menor de edad. |
| `ej3_calculadora` | Calculadora de dos números (suma, resta, multiplicación y división con o sin resto). |
| `ej4_buclesDoWhileFor` | Muestra la tabla de multiplicar de un número del 1 al 10 (`for`), repite si no es válido (`do while`) y tiene un modo de sumas acumuladas (`while`). |
| `ej5_arrayList` | Teoría de `ArrayList`: añadir, obtener, tamaño y eliminar elementos. |
| `ej6_hashMap` | Teoría de `HashMap`: añadir, leer, comprobar si existe, eliminar y recorrer una agenda. |
| `ej7_switch` | Menú con `switch` que se repite hasta que se introduce 7 para salir. |
| `ej8_agendaContactos` | Agenda de contactos con `HashMap`: buscar teléfono, listar contactos e historial de búsquedas. |
| `ej9_funciones` | Ejemplos básicos de funciones (métodos `static`) con y sin valor de retorno. |
| `ej10_calculadoraFunciones` | Calculadora con menú `switch` donde cada operación es una función; controla la división entre cero. |
| `ej11_clasesPerro` | Primera clase: `Perro` con atributos, constructor y métodos (`ladrar`, `info`). |
| `ej12_clasesCoche` | Clase `Coche` con atributo privado y métodos para acelerar, frenar y mostrar información. |
| `ej13_gettersSetters` | Clase `Persona` con atributos privados, getters/setters (con validación de edad) y método `presentarse`. |
| `ej14_herenciaAnimales` | Herencia: `Perro` y `Gato` heredan de `Animal` (`extends`, `super`) y añaden sus propios métodos. |
| `ej15_herenciaVehiculos` | Herencia: `Coche` y `Moto` heredan de `Vehiculo`; la moto indica si tiene sidecar. |
| `ej16_tryCatch` | Pide un número hasta que sea válido, controlando el error con `try / catch`. |
| `ej17_archivos` | Escribir, añadir líneas y leer un archivo de texto con `BufferedWriter` / `BufferedReader`. |
| `ej18_matrices` | Introducción a las matrices (arrays de dos dimensiones). |
| `ej19_parqueMatrices` | Mapa 10x10 de un parque con elementos colocados al azar; los cuenta y permite consultar una coordenada. |
| `ej20_algoritmia` | Algoritmia básica: números primos y factorial. |
| `ProyectoBanco` | Proyecto de banco: cuentas de ahorro y corriente (herencia), ingresos, retiradas, intereses e historial de movimientos. |
